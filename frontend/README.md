# Agentic Geo-Spatial Intelligence frontend

React, Vite, Leaflet, Recharts, and Lucide. Run `npm ci` then `npm run dev` with the FastAPI backend on port 8080. Run `npm run build` for the single-server production build.

Feature components are in `src/components`; API access is in `src/lib/api.js`. Full setup, methodology, and limitations are documented in the project-root README.
